How this experience works

The simulated assistant connects to a real MCP service over Streamable HTTP using protocol 2025-11-25. It discovers tools and calls them to check inventory, propose itineraries, confirm reservations and release places on cancellation. Confirmation rechecks current capacity and prevents duplicate reservations.
